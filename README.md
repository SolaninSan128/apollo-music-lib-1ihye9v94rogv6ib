# Harmonia 的八音盒

Static offline music library (GitHub Pages). No accounts or chat logs in this repo.

- 歌单 / **每日推荐** / 歌手
- 每日：按天卡片 → `#/daily/<date>` 详情打分
- 评分同步（静态站无法主动推助手）：
  1. **提交到 GitHub**（推荐）：打开私有收件箱预填 Issue，点 Create → Action 写入 `ratings/inbox/`，助手用 `gh` 读取  
     仓：https://github.com/SolaninSan128/harmonia-ratings-inbox
  2. 系统分享 / 复制短包 `HB|…` 粘贴私聊
  3. 不能把 GitHub token 写进前端（密钥会暴露）

Open `index.html` or the Pages URL. iPhone: Share → Add to Home Screen.
