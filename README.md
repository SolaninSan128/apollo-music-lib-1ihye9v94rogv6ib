# Harmonia 的八音盒

Static offline music library (GitHub Pages). No accounts or chat logs.

- 歌单 / **每日推荐** / 歌手
- 每日：先按天卡片列表，点进 `#/daily/<date>` 详情打分；右滑或返回回到列表
- 评分存本机 localStorage；有未同步时顶部出现同步条，一键分享/复制短包 `HB|…` 粘贴给 Harmonia（静态站无法主动推消息）

Open `index.html` or the Pages URL. iPhone: Share → Add to Home Screen.
